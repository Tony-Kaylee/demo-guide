Rev.io PSA Integration Overview

ConnectWise RMM + Rev.io PSA

Connect customer, endpoint, alert, and ticket workflows so service teams can work from accurate customer context in Rev.io PSA.

Current capability overview • September 2026

Integration at a glance

The ConnectWise RMM integration aligns companies and monitored endpoints with Rev.io customers and assets, then converts qualifying RMM alerts and tickets into actionable PSA work. Rev.io remains authoritative when synchronized customer data conflicts.

CustomerRev.io customer records align to ConnectWise RMM companies.
SiteRev.io addresses map to company sites in ConnectWise RMM.
EndpointSelected RMM endpoints synchronize into Rev.io as assets.
AlertAlerts meeting the configured severity can create PSA tickets.
ResolutionLinked tickets can close automatically when alerts clear.

What the integration supports

Customer and company synchronization

Rev.io customers can be created and updated as ConnectWise RMM companies. New companies may also be matched to Rev.io customers, with optional limited inbound synchronization.

Address and site alignment

Each Rev.io customer address is represented as a site under the corresponding ConnectWise RMM company.

Endpoint-to-asset synchronization

Platform, network, and cloud endpoint categories can be selected for synchronization into Rev.io assets and assigned to a chosen Rev.io asset type.

Alert-to-ticket automation

ConnectWise RMM alerts can create Rev.io tickets based on a configurable minimum severity and selected Rev.io ticket type.

Manual ticket synchronization

Non-alert RMM tickets can synchronize bidirectionally. Manually created Rev.io tickets may also be pushed to ConnectWise RMM when enabled.

Automated ticket closure

When enabled, a linked Rev.io ticket can close automatically after the originating RMM alert clears.

Synchronization and control

  • Account and company synchronization runs automatically every 30 minutes.
  • Rev.io-to-ConnectWise RMM synchronization runs first; optional reverse synchronization follows.
  • Rev.io is authoritative when synchronized records conflict.
  • Confident initial company matches can link automatically; uncertain matches remain pending for review.
  • Create Mode controls whether new Rev.io customers automatically become ConnectWise RMM companies or wait for manual linking.
  • Optional write-back can place the Rev.io asset ID in ConnectWise RMM custom fields.
Designed for controlled deployment: Customer matching, endpoint categories, alert severity, ticket direction, default service board, ticket source, and auto-close behavior are configuration choices—not hard-coded assumptions.

Data boundaries

Optional inbound company synchronization is intentionally limited. Rev.io remains the system of record, and billing, contracts, phone, email, website, and address details are not broadly imported from ConnectWise RMM into Rev.io as authoritative commercial data.

Implementation prerequisites

  • Administrator access to ConnectWise Asio.
  • OAuth 2.0 Client ID and Client Secret with company and site access.
  • An active Rev.io bill profile for customers created from ConnectWise RMM.
  • A dedicated Rev.io service account is recommended for audit clarity.
  • Existing Rev.io ticket type, status, asset type, and optional ConnectWise service-board/source values.
Recommended implementation sequence: establish credentials → configure customer matching → validate asset synchronization → pilot alert thresholds → enable ticket synchronization → validate closure and exception handling before broader rollout.
