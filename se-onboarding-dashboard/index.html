Revii Moments

Use AI where it improves speed or credibility.

Revii should punctuate the demo. It should not become the whole demo.

Best Moments

  • Customer activity summary
  • Open ticket and recent ticket analysis
  • Create ticket from natural language
  • Add internal activity note
  • Ask analytics questions

Practice Prompts

  • Summarize the last 90 days of activity
  • Create a service ticket for a customer
  • Add an internal note to ticket ID
  • Show tickets by severity
  • Find customers with most open tickets

Guardrails

  • Use tested prompts in live demos
  • Do not overuse AI
  • Use normal workflows when clearer
  • Review sensitive data before sharing
