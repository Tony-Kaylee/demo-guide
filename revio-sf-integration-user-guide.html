Overview

The Rev.io PSA - Salesforce integration keeps customer, contact, opportunity, and operational visibility data aligned between Salesforce and Rev.io PSA.

SalesforceCRM source for Accounts, Contacts, and sales stages.
→
PrismaticHosted orchestration, configuration, logging, and sync execution.
→
Rev.io PSAOperational system for service delivery, ticketing, and customer management.
AccountsSalesforce Accounts sync to Rev.io PSA Customers.
ContactsSalesforce Contacts sync to PSA Contacts under the linked Customer.
OpportunitiesQualified Salesforce Opportunities can create or update PSA Opportunities.
PSA connection handling: customers should not need to enter PSA User/API information in the setup wizard. Rev.io provisions the PSA connection inside the customer's integration instance.

Before You Start

Access Needed

  • Salesforce admin access
  • Permission to create custom fields
  • Permission to retrieve or reset a Salesforce security token
  • Access to the Rev.io integration activation page
  • Confirmation from Rev.io that PSA connection provisioning is complete

Decisions to Make

  • Which Salesforce Account Type values should sync
  • Which Opportunity stage should trigger PSA Opportunity creation
  • Whether Opportunity sync should be enabled at launch
  • Who owns credential rotation and support escalation

Estimated setup time: 30-45 minutes for configuration and basic validation.

Salesforce Field Setup

The integration uses custom fields to store Rev.io IDs and PSA visibility data. These fields allow future syncs to update existing records instead of creating duplicates.

Create the Fields

  1. In Salesforce, open Setup.
  2. Open Object Manager.
  3. Select Account, Contact, or Opportunity.
  4. Open Fields & Relationships, then select New.
  5. Choose the field type shown below and enter the exact API name.
  6. Set field-level security so the integration user can read and write the field.
  7. Add the field to relevant page layouts if users should see it.

Salesforce Credential Setup

The customer enters Salesforce credentials in the setup wizard. A dedicated Salesforce integration user is recommended.

SettingExampleNotes
Salesforce Instance URLhttps://yourcompany.my.salesforce.comUse the exact production or sandbox URL.
Salesforce Usernameintegration.user@company.comDedicated integration user recommended.
Salesforce PasswordStored securely in the wizardFollow customer password policies.
Salesforce Security TokenToken from Salesforce emailRequired for username/password authentication.

Reset a Security Token

  1. Log in to Salesforce as the integration user.
  2. Select the profile avatar, then open Settings.
  3. Under My Personal Information, select Reset My Security Token.
  4. Select Reset Security Token.
  5. Copy the token from the Salesforce email.
Security tokens reset when the Salesforce password changes. If the password is rotated, update the integration credentials with the new token.

User Guide

Sales Users Keep Accounts, Contacts, and Opportunities current in Salesforce. Do not edit Rev.io ID fields manually. Review Open PSA Tickets before customer calls.
Salesforce Admins Maintain integration user access, field permissions, token rotation, and picklist values used by sync filters or mappings.
PSA Users Use Rev.io PSA as the operational system. Avoid manually creating duplicates for records expected to sync from Salesforce.

Fields Users Should Not Edit

  • Account: Rev_io_ID__c
  • Account: Open_PSA_Tickets__c
  • Contact: Rev_io_Contact_ID__c
  • Opportunity: Rev_io_ID__c
  • Opportunity: PSA_Bill_Profile_Id__c, unless Rev.io has instructed the customer to maintain it manually

Validation Test Plan

Account Creation

  1. Create or select a Salesforce Account matching the Account Type Filter.
  2. Run the sync or wait for the trigger.
  3. Confirm a PSA Customer appears.
  4. Confirm Rev_io_ID__c is populated.

Account Update

  1. Update phone or website on the Salesforce Account.
  2. Run the sync.
  3. Confirm the existing PSA Customer updates.
  4. Confirm no duplicate is created.

Contact Sync

  1. Add a Contact to a synced Account.
  2. Run the sync.
  3. Confirm it appears under the correct PSA Customer.
  4. Confirm Rev_io_Contact_ID__c is populated.

Opportunity Sync

  1. Create an Opportunity under a synced Account.
  2. Move it to the trigger stage.
  3. Confirm the PSA Opportunity is created.
  4. Confirm Rev_io_ID__c is populated.

Troubleshooting

Accounts Are Not Syncing

  • Confirm the Account matches the Account Type Filter.
  • Confirm Rev_io_ID__c exists and is writable.
  • Confirm the Salesforce connection test is successful.
  • Confirm the integration user can access the Account.

Contacts Are Not Syncing

  • Confirm the Contact is related to an Account.
  • Confirm the parent Account already has a Rev.io ID.
  • Confirm Rev_io_Contact_ID__c exists and is writable.

Opportunities Are Not Syncing

  • Confirm Opportunity sync is enabled.
  • Confirm the Opportunity stage matches the trigger stage.
  • Confirm the related Account has synced to PSA.
  • Confirm PSA stage, type, and status values still exist.

Authentication Errors

  • Confirm Salesforce username, password, token, and instance URL.
  • Confirm the Salesforce integration user is active and has API access.
  • For PSA authentication errors, confirm with Rev.io that the PSA connection was provisioned inside the customer's integration instance.

Go-Live Checklist

  • Salesforce fields created with exact API names
  • Field-level security granted to the integration user
  • Salesforce connection tested successfully
  • PSA connection provisioned by Rev.io
  • Account Type Filter confirmed
  • Opportunity trigger stage confirmed
  • Opportunity mappings reviewed
  • Debug Mode off for production
  • Validation test plan completed
  • Support owner identified
  • Credential rotation owner identified

Support Handoff

When escalating an issue, include:

  • Customer name
  • Salesforce org type: sandbox or production
  • Salesforce Account, Contact, or Opportunity record URL
  • Rev.io PSA Customer, Contact, or Opportunity ID if known
  • Approximate time the sync was expected to run
  • Screenshot or copy of the integration error if available
  • Whether the issue affects one record or many records
Support should avoid asking customers for PSA API credentials unless Rev.io has confirmed that this customer's integration instance was not provisioned correctly.
