# Process Parity Register site

Static, dependency-free GitHub Pages presentation of the **Rev.io PSA Deal-Killer Process-Parity Register**, revised 2026-11-24.

## Contents

- `index.html` — semantic page structure
- `styles.css` — responsive, accessible light/dark visual system
- `app.js` — the 13 build needs, search/filtering, expansion controls, and persisted theme toggle
- `.nojekyll` — direct GitHub Pages serving
- `desktop-preview.png` and `mobile-preview.png` — full-page verification captures

## Run locally

Serve this directory with any static server, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

No build step or external dependencies are required. The page includes only the ranked register; omitted/workaround and later source sections are intentionally excluded.
